One letter for my day: **Z** — for "zombie", a day spent shuffling through tasks on zero sleep, half awake, fully committed. Vivid, funny, and true.

## Run it

```sh
python3 main.py
```

It writes exactly one character, `Z`, to `/output/entry.txt` — nothing else.
